## 💻 Run Locally

Want to explore or modify the portfolio locally?

### 1️⃣ Clone the repository

```bash
git clone https://github.com/rohan250903/my_portfolio.git
```

### 2️⃣ Navigate to the project

```bash
cd my_portfolio
```

### 3️⃣ Open the project

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.
